# DevPals - Turning Ideas Into Digital Products

DevPals is a modern digital agency and product engineering web application designed to turn ambitious concepts into world-class digital products. Built with Next.js 15, React 19, TypeScript, Tailwind CSS, and Motion.

---

## 🚀 Features

- **High-Converting Hero Section**: Dynamic animations, responsive typography, and clear calls to action.
- **Service Offerings**: Detailed service breakdowns (Web Development, Mobile Applications, AI & Automation, Digital Platforms, Consulting & Strategy).
- **Interactive Modals**: Case studies, deep-dive service information, sprint process scopes, and lead generation modals.
- **Process Lifecycle**: 5-step engineering roadmap (Discover, Design, Build, Test, Launch).
- **Tech Stack Explorer**: Multi-tier architecture overview covering frontend, backend, infrastructure, AI/data, mobile, and integrations.
- **Case Studies**: Showcase of real-world products (Wallett, MediCare+, ShopNext).
- **Lead Capture & Newsletter**: Contact forms with interactive state handling.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🏃 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm / yarn / pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abdullahparvaiz07/DevPals.git
   cd DevPals
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Scripts

- `npm run dev`: Start the Next.js development server
- `npm run build`: Build production-ready bundle
- `npm run start`: Start the production server
- `npm run lint`: Run ESLint checks
